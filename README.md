# 🌾 KrishiShare (AgroMaster) - Digital Agriculture Ecosystem

KrishiShare is a comprehensive digital platform designed to empower farmers and agricultural stakeholders by providing centralized access to essential farming resources.

## 🚀 Features

- **🚜 Equipment Rental:** Real-time booking of tractors and agricultural machinery.
- **🛒 Krishi Mart:** Integrated e-commerce marketplace for farm essentials (seeds, fertilizers).
- **🏛️ Government Schemes:** Centralized database of agricultural subsidies and schemes.
- **🛡️ Master Admin Control:** Robust dashboard for system monitoring and user management.
- **🌦️ Weather Updates:** Live localized weather data for better crop planning.
- **🔐 Secure Authentication:** OTP-based login (Email & SMS) and Google OAuth integration.
- **📍 Live Tracking:** Real-time map tracking for order deliveries and equipment movement.

## 🛠️ Technology Stack

- **Frontend:** React.js, Tailwind CSS, Lucide Icons, Socket.io-client.
- **Backend:** Node.js, Express.js, Socket.io.
- **Database:** MongoDB Atlas (NoSQL).
- **Security:** JWT (JSON Web Tokens).

## 📦 Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshaljagdale0222/KrishiShare-.git
   ```

2. **Frontend Setup:**
   ```bash
   cd krishi-share-frontend
   npm install
   npm run dev
   ```

3. **Backend Setup:**
   ```bash
   cd backend
   npm install
   npm run dev
   ```
